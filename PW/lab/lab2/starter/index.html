Pagina mea web www.alexbogdan.tech

Prezentare

Pentru acest curs am ales să îmi urc paginile html pe site-ul meu de la adresa:
www.alexbogdan.tech.

Pentru că nu am vrut să îl pun pe VPS am ales să îl hostez pe telefonul meu.

Sectiune tehnica

Hosting și Networking

Pentru a găzdui unui site web pe telefon android am folsit următoarele soluții software:

  • Termux: un emulator de terminal de Linux pe android.
  • Proot-distro: un manager de pseudo-root-uri de linux care rulează pe Termux.
  • Pseudo-root de Debian GNU/Linux.
  • Nginx: Serverul pe care rulează pagina web, pe proot Debian, la adresa localhost:8080
  • Cloudflare: Prin daemon-ul cloudflared care îmi crează un tunel către serviciul or de DNS
  • Registrarul meu, configurat să redirecționeze către Cloudflare.

Nginx rulează în Debian, expune portul 8080 pe adresa localhost. Termux rulează cloudflared
pentur a menține tunelul către Cloudflare. Prin setările DNS de pe domeniu Cloudflaare își face magia
iar site-ul este livrat în clienți de web (Browsere). Cloudflare se ocupă și de certificate pentur https
și îmi asigură protecție DDOS.

Actualizre cu git

Gitea și cronjob de git fetch din localhost:3000/alex/html.git

  1. Gitea e un server personal de git care rulează ca proces separat pe același proot de Debian.
  2. Astfel cu un simplu git fetch automat cu cron la 5 minute, eu pot să actualizez acest website de pe orice PC cu git printr-o comanda git push.
  3. To do:

  4. Misc: Am și o comandă a programului pandoc care îmi convertește fișiere markdown în pagini html ce pot fi hostate pe site. Folosesc această soluție pentru a scrie formul matematice în latex în fișiere markdown și în cele din urmă convertie în html.

Concluzie

Site-ul funcționeză, DAR în corpul P mai ales recepția 4G e câteodată proastă și asta îmi strică tunelul cu cloudflare câteodată.
În schimb de obicei funcționează majoritatea timpului, dacă conexiunea este constant bună.
De asemenea înt-o zi îmi consumă în jur de 20% din baterie.
